## 1. Goal definition

The goal is reached when all are true:

```text
market_regime inference logic exists outside WarRoom UI render path
inference producer writes versioned market_regime artifacts
WarRoom prediction cards read latest_cards.json read-only
operator can see market-regime result cards in UI
card detail shows reasons/conflicts/invalidation/source contribution
prediction traces record why each horizon result was produced
outcome resolver can score expired predictions
calibration can compare parameter sets and source/hypothesis trust
no broker/order/ledger/AutoTrade permission is introduced by this work
```

Human-visible done state:

```text
WarRoom shows market-regime cards generated by the inference artifact path, not sample cards.
Each card has horizon, regime label, confidence %, tag, freshness badge, and detail overlay.
The UI status/caption says artifact latest_cards is used.
A latest trace/outcome path can be inspected from D-hot artifacts.
```

## 2. Non-negotiable boundaries

```text
UI must not invoke classifier or D-hot preview inference during render.
UI reads latest_cards.json or falls back to sample cards.
Inference producer owns source reading, feature building, classifier, trace, and latest artifacts.
Collector owns market data collection.
AutoTrade remains disconnected.
Broker/private API remains disconnected.
```
