2) **`docs/仕様書一式/`**

- 仕様書の入口が必要なら `docs/仕様書一式/README.md` を作ってよい（ただし正準入口は `_INDEX.md`）。

- 文書と実装が矛盾した場合は、まず `_INDEX.md` に従って「正準仕様」を確認し、必要なら文書側も更新して整合を取る。
